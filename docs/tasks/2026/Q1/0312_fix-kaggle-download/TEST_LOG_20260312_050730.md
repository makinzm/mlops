## FAILED テスト

### 1. `test_competition_unzips_when_unzip_true`

```
AssertionError: assert False
  where False = (tmp_path / 'train.csv').exists()
```

**原因**: `_download_competition` は `competition_download_files` を呼ぶだけで ZIP 展開をしない。
`competition_download_files` に `unzip` パラメータが存在しない（Kaggle API v1.8.3）。

---

### 2. `test_dataset_unzips_when_unzip_true`

```
AssertionError: assert False
  where False = (tmp_path / 'train.csv').exists()
```

**原因**: `_download_dataset` は `dataset_download_files(unzip=True)` を呼ぶが、
API の unzip は「ダウンロードが発生したとき」のみ動作する。
モックではダウンロードイベントが発火しないため、ZIP が展開されない。
また既存 ZIP があるケースでも同様に展開されない。

---

### 3. `test_download_dataset_fails_when_files_exist_and_force_false`

```
Failed: DID NOT RAISE <class 'FileExistsError'>
```

**原因**: `_download_dataset` に既存ファイルの事前チェックが存在しない。
Kaggle API は `force=False` のとき静かにスキップするだけ。

---

### 4. `test_download_competition_fails_when_files_exist_and_force_false`

```
Failed: DID NOT RAISE <class 'FileExistsError'>
```

**原因**: `_download_competition` も同様に既存ファイルチェックがない。

## 修正方針（GREEN フェーズ）
