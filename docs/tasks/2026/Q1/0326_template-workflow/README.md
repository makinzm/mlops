# Template Workflow ドキュメント作成

## 目的

このリポジトリをテンプレートとして Kaggle コンペ用リポジトリを作成し、
コンペ終了後に汎用関数をテンプレートに戻すワークフローをドキュメント化する。

## 課題

1. テンプレートからコンペ用リポジトリを作るたびに `.env` 等の再設定が面倒
2. コンペ終了後に有用な関数をテンプレートにバックポートする手順が未定義
3. 上記のワークフロー全体が未ドキュメント

## 方針

- **リポジトリ作成**: `git clone` + `upstream` remote で接続維持
- **`.env` 共有**: `~/.config/mlops/.env` にマスターファイルを置き、シンボリックリンク
- **バックポート**: コンペリポジトリを remote 追加 → `cherry-pick` → PR
